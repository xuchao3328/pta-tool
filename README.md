# PTA 工具合集

一套面向 [拼题A（PTA / pintia.cn）](https://pintia.cn) 的 [Tampermonkey](https://www.tampermonkey.net/) 用户脚本，用来减少刷题时的重复操作：AI 解析题目、一键完成客观题与编程题、隐藏不关心的题目集卡片、快速返回题目集列表。

> 如果觉得工具好用，欢迎点个 ⭐ Star，或请我喝杯咖啡（详见脚本右下角「作者的话」）

## 功能一览

| 模块 | 说明 |
| --- | --- |
| **AI 解析** | 题目旁注入「解析」按钮，调用大模型给出解题思路与答案。客观题（单选 / 多选 / 判断 / 填空）直接给选项，编程题按题干与语言给参考代码，SQL 题按数据库方言生成 |
| **一键完成** | 悬浮面板一键跑完整套题：客观题识别类型后自动作答回填，编程题生成代码后写入 CodeMirror 编辑器；题干带图时把图片发给视觉模型；支持实时日志与中途停止 |
| **隐藏题目集** | 在题目集卡片上添加隐藏按钮，把不关心的题目集从列表中移除，状态保存在本地 |
| **返回跳转** | 把 PTA 内部页面的返回箭头改为跳回题目集列表，避免逐层后退 |
| **作者的话** | 嵌在「一键完成」悬浮面板底部的一小块：GitHub 主页与微信赞赏码，点标题可折叠。面板被关掉时它也随之消失 |

> 「全部题目集筛选栏」（把活跃题目集页的筛选栏复刻到全部题目集页）目前仍是**独立脚本，尚未并入本合集**。

## 安装

1. 浏览器安装 [Tampermonkey](https://www.tampermonkey.net/) 扩展（Chrome / Edge / Firefox 均可）。
2. 打开 [`pta-all-in-one.user.js`](./pta-all-in-one.user.js)，Tampermonkey 会自动弹出安装页；也可以把文件下载后拖进浏览器窗口。
3. 如果你之前装过 PTA 相关的**单个脚本**，请把它们**禁用**，否则「解析」按钮与悬浮面板会出现两套。

## 配置 API Key

「AI 解析」和「一键完成」共用同一个 DeepSeek API Key 存储键，配置一次即可：

1. 前往 [DeepSeek 开放平台](https://platform.deepseek.com/) 申请 API Key；
2. 点击浏览器中的 Tampermonkey 图标 → 找到本脚本 → 点击 **「设置 DeepSeek API Key（解析 / 一键完成通用）」**，粘贴保存。

> 从旧版「一键完成」升级的用户无需重新填写，脚本会自动迁移原有 Key。

## 使用说明

### AI 解析

题目旁边会出现「解析」按钮，点击后调用模型并展示结果，面板可折叠。同一道编程题只会保留一条「解析」工具条，不会重复出现。

### 一键完成

页面右侧出现悬浮面板，点击 **▶ 开始** 自动作答：

- **客观题**：识别题型后填入对应选项 / 填空内容；
- **编程题**：请求模型生成代码并写入编辑器；
- **题干带图**：图片会一并提交给视觉模型；
- **SQL 题**：根据题干与所选语言判断数据库方言（MySQL / SQL Server / Oracle / PostgreSQL），按方言生成语法正确的语句；
- 过程有实时日志，随时可点 **⏹ 停止**（会在当前题目结束后停下）。

如果代码写入编辑器失败，可用面板里的 **「复制代码」** 手动粘贴。

### 作者的话

「❤️ 作者的话」就在上面这个一键完成悬浮面板的最底部：点标题可以折叠 / 展开，展开后是留言、GitHub 主页链接和微信赞赏码。它跟着面板走——面板被拖动时一起移动，点面板的「✕」关掉后就不再显示（刷新页面可恢复）。也可以用 Tampermonkey 菜单里的 **「ℹ️ 关于作者 / 赞助」** 快速展开。

### 隐藏题目集

题目集卡片上会出现隐藏按钮，点击后卡片从列表移除，状态保存在本地。

### 返回跳转

在题目、题目详情等页面点击左上角返回箭头时，直接跳回题目集列表。

## 常见问题

**Q：页面上出现两套「解析」按钮 / 悬浮面板？**
A：说明本合集与你之前装的单个脚本同时启用了，请禁用重复的那一份。

**Q：AI 解析或一键完成没反应？**
A：先在 Tampermonkey 菜单里确认 API Key 已填写；再打开浏览器控制台查看是否有报错（请求 DeepSeek 失败通常是 Key 无效或额度不足）。

**Q：一键完成写入代码失败？**
A：可改用悬浮面板中的「复制代码」，手动粘贴到编辑器。

**Q：赞赏码在哪里？扫不出来怎么办？**
A：在「🚀 一键完成」悬浮面板的最底部，点「❤️ 作者的话」标题即可展开；如果已经折叠，点 Tampermonkey 菜单里的 **「ℹ️ 关于作者 / 赞助」** 也能展开。面板被「✕」关掉时它一起消失，刷新页面即可恢复。
